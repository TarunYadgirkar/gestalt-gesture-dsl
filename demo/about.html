Gesture recognition you can argue with

Most hand-tracking code hides its decisions inside if-statements and magic numbers. When a pinch fires at the wrong moment, you are left guessing which threshold was wrong. Gestalt makes gestures declarative, compiles them into state machines you can watch run, and ships the harness that measures whether a change helped.

The problem

A gesture is a pose that persists, changes and ends. It has to stay correct while the tracker drops frames, while a hand slides out of view, and while the model swaps its left and right labels mid-motion. Each of those is a chance to fire when the user did nothing.

False positives are the failure that matters most. A missed gesture is one the user repeats. An invented gesture is a deleted document or a dismissed menu. The system is built to make spurious fires expensive to introduce and easy to detect.

Gestures are data

A gesture definition names its conditions, its states and the transitions between them. This is the whole of pinch: 

name: pinch
hands: 1
priority: 10

predicates:
  pinched:
    distance: { a: thumb_tip, b: index_tip, lt: 0.05, exit: 0.075 }

states:
  - id: idle
    transitions:
      - when: pinched
        to: closed
        reason: thumb and index tips closed
        emit: { phase: start }

  - id: closed
    accept: true
    transitions:
      - when: { not: pinched }
        to: idle
        reason: fingers separated past the release threshold
        emit: { phase: end }

Two thresholds. The fingers must close to 0.05 to latch the pinch on, and must open past 0.075 to release it. Without that gap, a hand resting on the boundary emits a burst of start and end events as noise pushes it back and forth. This is hysteresis, declared on the condition that needs it instead of bolted on as a global smoothing pass.

What the DSL can say

  • distance, angle, curl and speed are conditions over named landmarks.
  • all, any and not compose them, and named predicates are reusable across states.
  • min_hold_ms makes a guard stay true continuously before it fires. Dwell-select uses it.
  • capture snapshots a value on entering a state, so scale and rotation have an anchor to measure against.
  • expr compares an expression to a threshold, for example abs(span / capture.anchor_span - 1) > 0.10.

Compiled, then watched

Each definition compiles to an explicit temporal state machine. describe() returns the states, the transitions and every guard with its numbers intact, and the running recognizer reports which guard is true right now. The panel on the live page draws exactly that. When a gesture fires, you can point at the transition that fired it and the value that crossed.

Where hand tracking goes wrong

Frames disappear

A tracker dropping frames mid-gesture must not cancel the gesture. Brief gaps are held through a grace window. A longer gap emits cancel with reason tracking_lost rather than a clean end, because the gesture was lost, and whatever is downstream needs to know the difference.

Hands swap identity

MediaPipe's Left/Right label flips under fast motion. Gestalt treats it as a hint: identity comes from spatial continuity, so the hand nearest to where a hand was last frame is that same hand. A single-frame label swap changes nothing.

Hands leave

A hand that exits the frame counts as dropout for the gestures bound to it. When it returns, it is a new hand with a clean machine, not a half-finished gesture resumed.

Gestures overlap

A pinch that starts moving is also a drag. Two pinched hands moving apart are also two drags. Instead of letting the first gesture hold the hand forever, a strictly higher-priority gesture preempts it: the incumbent is cancelled with preempted_by:<winner> so its effect can be undone, and the winner starts on the same frame.

The eval harness

A recognizer without measurement cannot be tuned. Every gesture ships with synthetic sessions whose true onset frames are known exactly, plus adversarial negatives built to be nearly right: a pinch that closes to 88% and stops, a drag too slow to count, a fist travelling at push speed.

For each gesture, the harness reports:

precision recall false positives per minute latency from true onset

Regression mode scores the whole corpus against a committed baseline and fails if any gesture degrades beyond tolerance, so a threshold tweak that quietly costs recall is caught at the commit.

What the numbers do not tell you. All 34 sessions come from the test suite's hand poser. They have perfect labels and clean geometry, which is what makes them useful for catching regressions. They say nothing about lighting, skin tone, occlusion or a real tracker's jitter. Measuring that needs recorded sessions, which the harness can already load but the repo does not ship yet.

It has already caught bugs. The harness found two mislabeled ground-truth intervals and one unrealistic piece of synthetic geometry: full pinches that closed to an exact zero gap, which made every distance threshold below the open-hand spacing score identically. Fixtures that cannot fail cannot tune anything.
