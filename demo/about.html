Gesture recognition you can argue with.

Most hand-tracking code hides its decisions inside a thicket of if-statements and magic numbers. When a pinch fires at the wrong moment you are left guessing which threshold betrayed you. Gestalt makes gestures declarative, compiles them into state machines you can watch run, and ships the measurement harness that tells you whether a change actually helped.

The problem

A gesture is not a pose. It is a pose that persists, changes, and ends — and it has to stay correct while the tracker drops frames, while a hand slides out of view, and while the model swaps its left and right labels mid-motion. Every one of those is a chance to fire when the user did nothing.

False positives are the failure mode that matters. A gesture you missed is a gesture the user repeats. A gesture you invented is a document deleted, a menu dismissed, a model flung across the room. So the whole system is built around making spurious fires expensive to introduce and easy to detect.

Gestures are data, not code

A gesture definition names its conditions, its states, and the transitions between them. Here is the whole of pinch: 

name: pinch
hands: 1
priority: 10

predicates:
  pinched:
    distance: { a: thumb_tip, b: index_tip, lt: 0.05, exit: 0.075 }

states:
  - id: idle
    transitions:
      - when: pinched
        to: closed
        reason: thumb and index tips closed
        emit: { phase: start }

  - id: closed
    accept: true
    transitions:
      - when: { not: pinched }
        to: idle
        reason: fingers separated past the release threshold
        emit: { phase: end }

Two thresholds, not one. The fingers must close to 0.05 to latch the pinch on, but must open past 0.075 to release it. Without that gap, a hand resting exactly on the boundary emits a burst of start/end events as noise pushes it back and forth. This is hysteresis, and it is declared on the condition that needs it rather than bolted on as a global smoothing pass.

What the DSL can say

  • distance, angle, curl, speed — conditions over named landmarks
  • all / any / not — composition, with named predicates reusable across states
  • min_hold_ms — a guard that must stay true continuously, which is how dwell-select works
  • capture — snapshot a value on entering a state, so scale and rotation have an anchor to measure against
  • expr — an expression compared to a threshold, e.g. abs(span / capture.anchor_span - 1) > 0.10

Compiled, then watched

Each definition compiles to an explicit temporal state machine. Not a black box — describe() returns the states, the transitions, and every guard with its numbers intact, and the running recognizer reports which guard is true right now. That is what the panel on the live page is drawing. When a gesture fires you can point at the transition that fired it and the value that crossed.

Four ways hand tracking lies to you

Frames disappear

A tracker dropping frames mid-gesture must not cancel the gesture. Brief gaps are held through a grace window; only a gap longer than that emits cancel with reason tracking_lost — never a clean end, because the gesture did not end, it was lost. The distinction matters to whatever is downstream.

Hands swap identity

MediaPipe's Left/Right label flips under fast motion. Gestalt treats it as a hint and nothing more: identity comes from spatial continuity, so the hand nearest to where a hand was last frame is that same hand. A single-frame label swap changes nothing.

Hands leave

A hand that exits the frame is dropout for the gestures bound to it. When it returns it is a new hand with a clean machine, not a half-finished gesture resumed from whenever it left.

Gestures overlap

A pinch that starts moving is also a drag. Two pinched hands moving apart are also two drags. Rather than let the first gesture to fire hold the hand forever, a strictly higher-priority gesture preempts it: the incumbent is cancelled with preempted_by:<winner> so its effect can be undone, and the winner starts on the same frame.

pinch fires as the fingers close
↓ hand starts translating
pinch-drag preempts it  pinch → cancel
↓ second hand joins, span changes
two-hand-scale preempts that  pinch-drag → cancel

The harness is half the project

A recognizer without measurement is a recognizer you cannot tune. Every gesture ships with synthetic sessions whose true onset frames are known exactly, plus adversarial negatives built specifically to be nearly right: a pinch that closes to 88% and stops, a drag too slow to count, a fist travelling at push speed.

The harness reports, per gesture:

precision recall false positives / minute latency from true onset

Regression mode scores the whole corpus against a committed baseline and fails if any gesture degrades beyond tolerance, so a threshold tweak that quietly costs you recall is caught at the commit rather than in a user's hands.

It has already earned its keep. The harness caught two mislabeled ground-truth intervals and one unrealistic piece of synthetic geometry — full pinches that closed to a mathematically exact zero gap, which would have made every distance threshold below the open-hand spacing score identically. Fixtures that cannot fail cannot tune anything.
